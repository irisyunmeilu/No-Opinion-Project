# No-Opinion-Project
This repository includes all the coding syntax and log files for our paper "Examining the Increases in Don’t Know Responses about Law Enforcement Among American Youth from 1976 to 2018"
Data: Monitoring the Future 12th Grade Survey Public Data, all the data is publicly available through ICPSR. 
Files: 
1.	“Setup and package_12th_form3. R” R code for downloading the data and merging data from multiple years
2.	“Measure and sample_12th_form3.R” R code for cleaning data and coding variables
3.	“Table 1 and Appendix D Code.R”  R code for (1) Table 1— weighted descriptive table for the full sample as well as descriptive statistics by cohort; (2) Appendix D. Unweighted descriptive
4.	“Table 2 Code.R” R code for Table 2. Logistic regression analysis of DK response by Cohort
5.	“Table 3 and Appendix C and F.do” STATA syntax file for BO Decomposition analysis. The code is for generating restuls in Table 3, Appendix C and Appendix F. 
6.	“Table 3_App C&F_Log file.smcl” STATA log file for BO decomposition results (Table 3 and Appendix C & F. 
7.	“Figure 1 and Figure 2 Code.R”  R code for Figures 1 and 2
8.	“Figure 3 and Appendix E Code.R” R code for Figure 3 and Appendix E. Appendix E is the model allowing all independent variables to interact with the cohort variable and Figure 3 visualizes the significant effects found in the decomposition analysis. 
9.	“Table 4_Figure 4_Appendix G.R” R code for Table 4, Figure 4, and Appendix G. Using feeling safe as outcome and assessing its association with DK responses. 
10.	“Appendix H. Imputation Code.R” R code for Appendix H, assessing the impact of DK responses on police perception estimates using Multiple Imputation.
